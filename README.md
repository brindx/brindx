## Sobre mí

Soy estudiante de Ingeniería en Sistemas Computacionales y desarrollador de
software enfocado en construir productos web, móviles y sistemas SaaS.

Trabajo desde la idea inicial hasta la implementación: arquitectura,
modelado de datos, interfaces, desarrollo, integración de servicios y
despliegue.

## Ingeniería

### Arquitectura

Diseño sistemas pensando en separación de responsabilidades,
mantenibilidad y evolución del producto.

### Datos

Modelo bases de datos relacionales con especial atención a
integridad, relaciones, seguridad y rendimiento.

### Frontend

Construyo interfaces con jerarquía visual clara, responsive design,
componentización y una experiencia consistente.

### Backend

Diseño APIs y servicios orientados a operaciones reales del producto,
